Coding Academy - Tugas Pemrograman Web 1

Website interaktif bertema Coding Academy yang dibangun menggunakan HTML dan CSS murni (serta sedikit JavaScript untuk validasi form dan navigasi dinamis). Proyek ini dibuat untuk memenuhi tugas mata kuliah Pemrograman Web 1.

🚀 Fitur Utama

Halaman Gallery (gallery.html):

Menampilkan 6 pilihan program pelatihan (Web Development, JavaScript, PHP & MySQL, Python, UI/UX Design, serta Git & GitHub).

Dilengkapi dengan gambar ilustrasi kegiatan dan deskripsi singkat.

Interaktif: Setiap kartu pelatihan dapat diklik untuk langsung mengarahkan pengguna ke halaman pendaftaran.

Halaman Pendaftaran (pendaftaran.html):

Formulir pendaftaran lengkap dengan isian:

NIK (16 digit)

Nama Lengkap

Pilihan Jenis Kelamin (Radio Button)

No HP

Alamat (Textarea)

Pilihan Bahasa Pemrograman yang Diminati (Dropdown/Select, otomatis terpilih jika diklik dari halaman Gallery).

Fitur konfirmasi: Muncul dialog confirm("Apakah Anda sudah yakin untuk menyimpan?") ketika tombol submit ditekan.

Jika memilih "Ya", sistem akan menampilkan ringkasan data hasil isian form secara rapi di bagian bawah halaman.

📁 Struktur File Proyek

tugas-web1/
│
├── gallery.html      # Halaman utama gallery 6 pelatihan
├── pendaftaran.html  # Halaman form pendaftaran dan hasil input
└── style.css         # Berkas stylesheet untuk tata letak dan desain web


💻 Cara Menjalankan Proyek di Komputer Lokal

Clone atau unduh repository ini ke komputer Anda.

Pastikan ketiga file (gallery.html, pendaftaran.html, dan style.css) berada di dalam satu folder yang sama.

Buka file gallery.html menggunakan browser web apa saja (Google Chrome, Mozilla Firefox, Microsoft Edge, dll).

Selamat mencoba!
